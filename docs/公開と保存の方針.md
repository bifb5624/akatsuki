# 公開と保存の方針

更新日: 2026-11-01（日本時間）

## ユーザーの希望

URLの公開もクラウド保存も、できるだけ無料にする。
Googleドライブを使うなら、アプリで作ったファイルもそこへ自動保存したい。
有料契約・公開・Googleアカウント接続はまだ行っていない。

## 役割分担

| 役割 | 候補 | 保存するもの |
| --- | --- | --- |
| アプリを開くURLと処理を動かす場所 | Renderの無料Nodeサービスを候補に比較 | アプリ本体。業務データはサーバーの一時ディスクに置かない |
| みんなで更新するデータ | SupabaseのPostgreSQL | 予定、設備、シフト、有給、社員の権限、ファイルのIDと保存状況 |
| 原本と作成した書類 | Googleドライブ | 領収書の原本、シフト・有給のPDF、依頼書 |

公開URLができても、会社のデータを誰でも読めるようにはしない。ログインと会社の所属確認を継続する。
Googleドライブはファイル置き場として利用し、有給残日数などを同時に更新するデータベースの代わりにはしない。
現在のアプリはSQLiteなので、Supabaseへの接続は未実装。無料サーバーへそのまま配置してよい状態ではない。

## 自動保存の予定

1. アプリでPDFなどを作成する。
2. サーバーがログインと会社の権限を確認し、保存待ちの記録を作る。
3. 登録済みのGoogleドライブのフォルダへ保存する。
4. ファイルのIDと保存結果をデータベースへ記録する。
5. 保存結果を画面に表示する。失敗した場合は「未保存」を表示し、端末へのダウンロードを残す。

同じ保存処理が同時に走らないように、データベースで処理IDを一意に管理する必要がある。
Googleへの送信成功後に通信が切れた場合は、ファイルの処理IDと内容のハッシュを確認して再利用する。
このうちGoogle側の保存処理はserver/google-drive.jsに用意し、模擬応答で検証した。接続画面、OAuth、暗号化したトークン保管、保存待ちキュー、実際の画面との連携は未実装。

## Googleドライブの接続

会社のGoogle Workspaceの共有ドライブか、通常のGoogleアカウントのマイドライブかを確認中。
共有ドライブなら会社にファイルを残しやすい。通常のアカウントの場合も、業務で管理するアカウントと保存先を決める。
管理者がGoogleの許可画面で接続する方式を想定。Googleパスワードをアプリやチャットへ入力させない。

作成したPDFの保存には、原則としてアプリが作成・明示選択したファイルだけを扱うdrive.file権限を検討する。
**指定した既存フォルダに手動投入された領収書をすべて自動読取する機能は、これだけでは実現しない。** フォルダを選ぶだけで中の全ファイルを読み取れる権限にはならない。
既存領収書の自動取込では、共有ドライブ・共有先の権限構成、Googleの追加許可と審査要件を別途検討する。広い読取権限が必要なら接続前に説明する。
アプリの退職者停止とは別に、Googleドライブの共有権限も解除する必要がある。ファイルを「リンクを知っている全員」へ自動公開する処理は作らない。

## 無料枠で確認できたこと

2026-11-01に公式GitHub上の料金ページ用データと資料を取得した。

- Supabase: Freeは月額0ドル、データベース500MB、ファイルストレージ1GB、アクティブプロジェクト2つ。1週間使われない無料プロジェクトは一時停止されると記載されている。
- Render: 公式Nodeサンプルにplan: freeの設定があることを確認。最新の無料枠の全条件・スリープ条件・カード要否は料金画面での再確認が必要。
- Googleドライブ: アカウント側の空き容量と利用条件に従う。現在の空き容量、Workspace契約、共有ドライブの有無は未確認。
- OCR・AI利用料、独自ドメイン、容量追加、メール配信は別途確認する。全機能がずっと無料とは保証しない。

料金サイト本体はこの実行環境のネットワーク制限で取得できなかったため、取得できた公式ソースに範囲を限定した。有料プランへの変更は行っていない。

## 次の実装順

1. SQLiteからPostgreSQLへ保存処理を対応させ、権限・同時更新・バックアップのテストを再実行。
2. 公開先とSupabaseのユーザー所有アカウントで無料枠を確認し、接続情報を安全に設定。
3. Googleアカウント種別とフォルダを確認し、管理者による接続・PDF自動保存を実装。
4. 領収書の自動取込とOCRは、許可範囲・保存量・費用を確認してから実装。

登録や接続が必要になった際は、初心者向けに一つずつ案内する。今はパスワードや秘密キーをチャットへ送る必要はない。
