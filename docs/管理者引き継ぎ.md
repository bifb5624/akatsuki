# 暁アプリ 管理者引き継ぎ

## 引き継ぐもの

- GitHubリポジトリの管理権限
- Renderサービスの管理権限と環境変数
- Tursoデータベースの管理権限
- Google Cloud OAuthプロジェクトと、アプリで接続するGoogleアカウント
- アプリ内の管理者アカウント
- Obsidian同期を使う場合は、新しい管理者が発行した接続コード

パスワード、APIキー、接続コードを文書やGitへ書かない。各サービスの正式なメンバー追加・所有権移管を使う。

## メールアドレスを変える順序

1. GitHub、Render、Turso、Google Cloudへ新しい管理者を追加する。
2. 新しい管理者でログインできることを確認する。
3. アプリの「社員・招待」から新しい管理者アカウントを作成する。
4. Google Driveを新しい管理アカウントへ移す場合は、フォルダの所有権とOAuth接続を確認する。
5. Renderの環境変数を更新してデプロイし、ログイン、予定保存、PDF読取を確認する。
6. すべて確認してから以前の管理者を停止する。

## Codexで修正するとき

Codexにはこのリポジトリを開き、変更内容を日本語で依頼する。`AGENTS.md`、`docs/requirements.md`、`docs/development-log.md`を先に確認させ、テスト後にGitHubへ反映する。秘密情報をチャットやソースコードへ貼らない。

書類整理を依頼するときは、次のように指定する。

> 未処理の書類を会社別に分類し、領収書は日付・発行会社・金額・税率・登録番号を抽出してください。確定せず、修正できる確認待ちとして登録してください。

## 確認項目

- `npm test`
- `npm run build`
- 管理者と一般社員の表示権限
- 3社と保有ビルの絞り込み
- Google Drive接続と未処理PDF読取
- ローカルPDFの原本がサーバーに永続保存されず、抽出結果だけが管理者に見えること
- 月別CSVの文字化けと内容
