# akatsuki：次の作業はここから

更新: 2026-11-01（日本時間）

## 最優先の新しい方針

**最初は個人アカウントで始め、後から法人化・アカウント変更がある前提で進める。**

- Googleドライブはまず個人アカウント。将来、法人用Googleアカウントや共有ドライブへ移す可能性がある。
- GitHub・ChatGPT・Obsidianも今のアカウントから別アカウントへ変更する予定。
- ユーザーは初心者。コードだけを渡さず、何ができるか、画面で何を押すかを日本語で説明する。
- 会話も含めてObsidianに記録を残したい。アカウントの記憶だけに頼らない。
- 専用Obsidianプラグインと同期APIは実装済み。アプリの公開URL、Macへの初回導入、実機同期は未完了なので接続済みではない。
- スマホ・タブレットのホーム画面へ追加するPWAの基本機能は実装済み。公開後の実機追加と通知は未完了。
- GitHub Actionsの自動検査、Render Blueprint、Macの「暁」用ワンクリックインストーラーを実装済み。外部サービスへのログインと実機操作は未完了。
- 利用端末はMac、Vault名は「暁」。Finder上の保存パスと同期方法は未確認。

## 作るアプリ

社長を含む4人で、渋谷区・新宿区のビル2棟を管理する。

- 設備・交換履歴・次回の交換目安・担当者。
- 今日・今週・今月の予定、カレンダー、タスク。
- シフト、有給・午前休・午後休、管理者承認、残日数、PDF。
- Googleドライブ指定フォルダの領収書読取・名前付け・経費/仕訳一覧。
- 業者候補と料金根拠、依頼書、通知。

デザインはネイビー・読みやすいゴシック体。スマホ・タブレット・PCに対応。
帳票の正式フォーマットは後日ユーザーから受領する。

## 実装済み・検証済み

- 設備、カレンダー、シフト、有給申請/承認、PDFの試作。
- PWAマニフェスト、アプリアイコン、サービスワーカーによるホーム画面追加の土台。
- 公開環境はRender FreeでLive。初期管理者ログインとTursoへの予定保存・再読込を確認済み。PC上部をコンパクト化し、320〜1920pxのレスポンシブ表示を再検証済み。
- Better Authによるログイン、管理者招待リンク、本人のパスワード設定、退職者停止とセッション失効。
- SQLiteによるサーバー共有保存、会社別権限、同時更新の上書き拒否、操作記録。
- 通常の画面と `?demo=1` の仮データ画面を分離。
- 実ブラウザで登録・共有・停止、8種類の幅で5画面のはみ出し確認を実施。
- 最新の `npm test` は25件成功。Googleドライブの4件は模擬APIでの検証。

## まだできていないこと

- 社員が使える公開URL、公開先へのデプロイ。
- Render用の自動設定 `render.yaml` と手順書は実装済み。Turso/Renderの実アカウント設定と公開URL発行は未完了。
- Turso用の共通保存層と移行ツールは実装済み。ユーザー所有Tursoへの実接続、移行、復元確認は未完了。
- Google OAuthのコード、管理画面、接続済みフォルダへのシフト・有給PDF自動保存は実装済み。Google Cloud設定、実接続、保存キュー、領収書の自動取込/OCRは未完了。
- 招待メール自動送信、パスワードを忘れた際のメール復旧、MFA。
- 通知、業者検索、依頼書、正式帳票、有給の繰越/失効ルール。
- NotebookLMの実接続。Obsidianは専用プラグインと同期APIを実装済みだが、公開URLとMac実機接続は未完了。
- ChatGPT会話の常時自動取得。現在取得できた会話は引き継ぎZIPへ保存済み。

## 保存・公開の候補

- 無料公開先候補: RenderのNodeサービス。
- 予定や有給など: Turso。
- 領収書原本・PDF・依頼書: Googleドライブ。

無料枠の制限・確認した出典は [公開と保存の方針](公開と保存の方針.md) に記載。
無料プランの一時ディスクへ現在のSQLiteをそのまま配置しない。

## 次に進める順番

1. 公開URLを用意し、作成済みの `Akatsuki Sync` プラグインをMacの「暁」へ一度導入する。公開前は引き継ぎZIPを手動で取り込める。
2. ユーザー所有のTursoを無料枠で作成し、実接続、移行、復元の検証を行う。コードとローカル検証は完了済み。
3. ユーザー所有の無料公開先、Turso、Googleドライブを設定する。まだ外部アカウントへの登録・契約は行っていない。
4. 個人Googleアカウントの接続方法を作り、将来の法人用への付け替え・ファイル移行を考慮する。
