# Obsidian「暁」の自動同期

更新: 2026-11-01（日本時間）

## できるようになったこと

専用プラグイン `Akatsuki Sync` を作成した。
MacのObsidianへ一度入れて接続すると、起動時と一定間隔（初期値15分）でAkatsukiの開発資料を取得する。

- 同期先: 「暁」Vault内の `akatsuki開発`。
- 対象: 引き継ぎ、要件、開発記録、公開/保存方針、アカウント移行、利用説明、画面画像、PDF見本。
- 認証: 管理者が発行するObsidian専用の読み取りコード。パスワードとは別で、停止可能。
- 保護: 内容のハッシュを照合。Obsidian側で手編集があれば、上書き前にコピーを残す。サーバーから消えたファイルを自動削除しない。

アプリ側には、接続コードの発行・一覧・停止と、許可した資料だけを配信するAPIを追加した。
パストラバーサル、未許可ファイル、停止済みコードを拒否するテストを実施した。

## まだ必要な一度だけの操作

プラグインをMacへ入れる操作は、Obsidianの制限上、一度必要。
配布ZIPに `暁にインストール.command` を同梱した。ZIPをすべて展開して実行すると、Macの標準的な保存場所にある「暁」を自動検出し、既存プラグインを日時付きフォルダへバックアップしてからインストールする。見つからない場合だけ「暁」フォルダの場所を入力する。
アプリの公開URLができた後、管理画面で接続コードを発行し、プラグイン設定へ貼り付ける。
現在はアプリが未公開なので、実際のMac「暁」との通信はまだ確認できない。

コミュニティプラグインとして一般公開すればObsidian内から導入しやすくなるが、GitHub公開、審査、保守が必要。現時点では会社用の非公開プラグインとして用意する。

## ChatGPT会話について

ObsidianプラグインからChatGPTアカウントの会話一覧を直接取得する公式経路は、今回の構成では利用できない。
ブラウザのCookie、ChatGPTのパスワード、非公開APIを読み取る方式は採用しない。

この開発スレッドで取得できた会話は、引き継ぎZIPの `会話記録.md` に保存済み。
今後、ChatGPT側の公式エクスポートや安全な連携口が利用できる場合は、同期サーバーへ取り込み、同じプラグインで配信できる。
それまでは「会話全文が常時自動保存される」とは扱わない。決定事項と作業結果は開発記録へ残して同期対象にする。
