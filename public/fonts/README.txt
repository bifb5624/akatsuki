Noto Sans JP Regular (static TrueType)
Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
Original file: NotoSansJP[wght].ttf
License: SIL Open Font License 1.1, see LICENSE.txt
Generated with fontTools.varLib.instancer.instantiateVariableFont(font, {'wght': 400}).
No design changes; the weight axis is fixed to Regular for PDF renderer compatibility.
The full static TTF is embedded in each PDF because pdf-lib/fontkit CJK subsetting
can produce missing glyph outlines despite correct text extraction.
The generated font is included, so Python/fontTools is not a runtime requirement.
Used as a self-hosted Gothic UI fallback as well.
