# Akatsuki Sync

MacのObsidian Vault「暁」へ、Akatsukiアプリの開発記録を自動同期する専用プラグイン。

## 動作

- Obsidian起動時と設定した間隔（初期値15分）で同期。
- 保存先は初期値 `akatsuki開発`。
- アプリの管理画面で発行した読み取り専用コードを使う。
- サーバー上のハッシュとダウンロード内容を照合してから保存。
- Obsidian側で同じファイルを編集していた場合は、上書き前に「手元の変更」コピーを残す。
- サーバーから消えたファイルをObsidian側で自動削除しない。

## 初回だけ必要な設定

1. このフォルダの `manifest.json`、`main.js`、`styles.css` を「暁」の `.obsidian/plugins/akatsuki-sync/` へ置く。
2. Obsidianの設定でコミュニティプラグインを有効にし、Akatsuki Syncをオンにする。
3. Akatsukiアプリの「社員・アカウント」→「Obsidian『暁』の自動同期」で接続コードを発行する。
4. プラグイン設定へアプリのHTTPS公開URLと接続コードを入力し、「今すぐ同期」を押す。

アプリはまだ公開されていないため、現時点では接続設定を完了できない。
接続コードはパスワードではなく開発資料の読み取り専用だが、他人へ渡さない。Macを紛失した場合はアプリ管理画面から停止する。

## 対象外

ChatGPTの会話履歴をChatGPTから直接取得する機能はない。公式の会話取得経路がない状態で、ブラウザのCookieや認証情報を読み取らない。
会話記録が同期サーバーへ安全に保存された場合は、同じ同期経路でObsidianへ配信できる。
